# GitHub Pages への公開手順

このフォルダは **公開専用のリポジトリ**です。
ここに置いたファイルが、そのまま児童のiPadから見えるURLになります。

---

## 最初の1回だけやること

### 1. GitHub で空のリポジトリを作る

1. <https://github.com/new> を開く
2. **Repository name** に `nippon-bouken` と入力
3. **Public** を選ぶ（Private だと無料プランでは公開できません）
4. **README や .gitignore は追加しない**（すでにこのフォルダにあるため）
5. 「Create repository」を押す

### 2. このフォルダをリポジトリにつなげて送る

このフォルダ（`Desktop/nippon-bouken`）で、次を順に実行します。

```bash
git remote add origin https://github.com/hama0704/nippon-bouken.git
```

```bash
git push -u origin main
```

### 3. GitHub Pages を有効にする

1. GitHub でそのリポジトリを開く
2. **Settings** → 左メニューの **Pages**
3. **Source** を「Deploy from a branch」
4. **Branch** を `main`、フォルダを `/ (root)` にして **Save**

2〜3分待つと、次のURLで公開されます。

```
https://hama0704.github.io/nippon-bouken/
```

## 児童に配るときの案内文（例）

> **にっぽん冒険記のはじめかた**
>
> 1. **Safari** で下のURLをひらきます
>    `https://hama0704.github.io/nippon-bouken/`
> 2. 画面の「共有」ボタン（□に↑のマーク）をおします
> 3. 「ホーム画面に追加」をえらびます
> 4. ホーム画面にできたアイコンから、いつでもあそべます
>
> ※ 一度ひらけば、インターネットにつながっていなくてもあそべます
> ※ きろくはこのiPadの中にだけのこります。ほかの人には見えません

URLの入力が大変な場合は、QRコードにして配ると確実です
（「QRコード 作成」で検索して出てくる無料サービスで作れます）。

**Safari で開く必要があります。** Chrome や、他のアプリの中のブラウザからだと
「ホーム画面に追加」のメニューが出ません。

## 直したあとに、公開ぶんを更新する

ファイルを直したら、次の3つを順に実行します。

```bash
git add -A
```

```bash
git commit -m "どこを直したかを書く"
```

```bash
git push
```

1〜2分でURLの中身が入れ替わります。
**児童の端末は、次にアプリを開いたときに自動で新しくなります。**
先生が何か番号を上げる必要はありません（詳しくは [PWA.md](PWA.md)）。

### 反映が1回遅れる場合があります

児童の端末は「まず保存済みの版を表示し、裏で新しい版を取り込む」という動きをします。
そのため、修正直後の1回目の起動では古い版が出て、
**2回目の起動から新しくなる**ことがあります。
授業で使う直前ではなく、前日までに更新しておくと確実です。

すぐ反映させたいときは、その端末で一度アプリを閉じて開き直してください。

## うまくいかないとき

### 404 と出る

- Pages の設定が終わっていない、または反映待ち（数分かかります）
- Branch が `main`、フォルダが `/ (root)` になっているか確認してください

### 画面が真っ白

ブラウザの開発者ツールのコンソールを見てください。
`404` が並んでいる場合は、フォルダごと置けていない可能性があります。
このアプリはすべて相対パスなので、**中身をまるごと**置けば動きます。

### ホーム画面に追加のメニューが出ない

Safari 以外で開いています。iOS では Safari が必要です。

## 手元で試すとき

公開せずに動きを見たいときは、このフォルダで次を実行します。

```bash
npx serve . -l 4321
```

表示された `http://localhost:4321` を開きます。

> `index.html` をダブルクリックしても動きません。
> ES Modules というしくみを使っており、ブラウザの安全上の制限で
> `file://` からは読み込めないためです。
