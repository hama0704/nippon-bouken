# オフライン動作（PWA）のしくみと更新手順

## できること

- iPad のホーム画面に追加すると、**アプリのように全画面で起動**します
- 一度開けば、**通信がなくても全機能が動きます**（機内モードでも遊べます）
- 校内Wi-Fiが不安定でも、読み込みで待たされません

---

## しくみ

3つのファイルで成り立っています。

| ファイル | 役割 |
|---|---|
| `manifest.webmanifest` | アプリ名・アイコン・起動時の見た目 |
| `sw.js` | ファイルを端末に保存し、次からはそこから読む |
| `index.html` の `<meta>` | iOS 用の全画面設定 |

`sw.js` は **まずキャッシュを返し、裏でネットワークからも取り直す** という動き方をします。
表示は端末に保存したファイルから即座に返るので、オフラインでも電波が弱くても同じ速さです。
それでいて、公開した修正は次にアプリを開いたときに自動で反映されます。

---

## 更新のしかた

**push するだけです。** 児童の端末は次に開いた時点で自動で新しくなります。

新しい版を見つけると、その場で読み込み直します。
「1回目は古いまま」ということはありません。
ただし遊んでいる最中には読み込み直しません（書きかけの答えが消えるため）。
起動から10秒より後に届いた更新は、次に開いたときに反映されます。

> 以前は「キャッシュにあれば返して終わり」だったため、
> `CACHE_VERSION` を上げ忘れると児童の端末が古い版のまま固定されました。
> 実際、地図を本物に差し替えたのに教室では古い地図のままになりました。
> 先生の端末では直って見えるので気づくのが遅れます。
> 人が毎回忘れずに数字を上げる、という前提に頼らない形にしています。

### 直ったかどうかの確かめ方

「せってい」画面のいちばん下に**アプリの版**が出ます。
児童に読み上げてもらい、先生が公開した版と同じなら最新です。

### CACHE_VERSION を上げるのはどんなとき

```js
const CACHE_VERSION = "v6";
```

**ファイルを削除したときだけ**です。消したファイルはキャッシュに残り続けるので、
番号を上げて古いキャッシュごと捨てます。ふだんの修正では上げる必要はありません。

### 新しいファイルを追加したときは PRECACHE_URLS にも足す

```js
const PRECACHE_URLS = [
  "./",
  "./index.html",
  ...
  "./src/ui/screens/新しい画面.js",   // ← 追加
];
```

ES Modules は import を辿って1ファイルずつ読み込まれるため、
すべてのファイルを列挙する必要があります。
書き忘れても、一度オンラインで開けば裏で取り込まれるので致命的ではありませんが、
**初回からオフラインで使いたい場合はそのファイルだけ読めません。**

## 更新が反映されないときの直し方

### 先生の端末で確認する

ブラウザの開発者ツール → Application → Service Workers →「Unregister」。
そのあとページを再読み込みします。

コンソールからでもできます。

```js
(async () => {
  for (const r of await navigator.serviceWorker.getRegistrations()) await r.unregister();
  for (const n of await caches.keys()) await caches.delete(n);
  location.reload();
})();
```

### 児童の iPad で確認する

1. ホーム画面のアイコンを長押しして削除
2. Safari →「設定 → Safari → 履歴とWebサイトデータを消去」
3. もう一度URLを開き、ホーム画面に追加

`CACHE_VERSION` を上げていれば、この作業は不要です
（次に開いたときに自動で新しい版に入れ替わります）。

## ホーム画面への追加のしかた（児童に伝えるとき）

**iPad / iPhone（Safari）**

1. アプリのURLを Safari で開く
2. 画面下（iPad は上）の「共有」ボタン（□に↑）を押す
3. 「ホーム画面に追加」を選ぶ
4. 名前を確かめて「追加」

**Android（Chrome）**

1. URLを開く
2. 右上の「⋮」→「アプリをインストール」または「ホーム画面に追加」

> Safari では **Safari で開かないとホーム画面に追加できません。**
> Chrome や、他のアプリ内ブラウザからだとメニューが出ません。
> 児童に案内するときは「Safari で開いてね」と一言添えてください。

## アイコンについて

`assets/icons/` の4つの PNG は、この教材の地図データそのものから
ドット絵として生成したものです（日本列島の形をしています）。

差し替えたい場合は、同じ名前・同じサイズの PNG を置くだけです。

| ファイル | サイズ | 用途 |
|---|---|---|
| `icon-192.png` | 192×192 | Android のホーム画面 |
| `icon-512.png` | 512×512 | スプラッシュ画面など |
| `icon-180.png` | 180×180 | iOS のホーム画面 |
| `icon-maskable-512.png` | 512×512 | Android の丸型・角丸に切り抜かれる版 |

`icon-maskable-512.png` は、まわり2割ほどが切り取られる前提で
中央に余白を多めにとってあります。ここを普通のアイコンにすると端が欠けます。

---

## HTTPS が必要です

Service Worker は **https:// か localhost でしか動きません**。
GitHub Pages は自動で https なので、そのまま使えます。
校内サーバーに置く場合は https 化が必要です
（http のままでもアプリは動きますが、オフライン機能とホーム画面追加が使えません）。
