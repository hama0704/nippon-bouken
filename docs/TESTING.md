```bash
cd prefecture-rpg
npm test
```

ブラウザで見たい場合は `tests/run.html` を開きます。

**82件**が、次のところを検査しています。

| 分野 | 検査していること |

| かな処理 | カタカナ→ひらがな、長音符、「認める書き方」の組み立て |
| 採点 | ○△×のきまり。**47県すべての漢字・読みで正しく判定されること** |
| 経験値 | 100/60/50/20/120、苦手克服ボーナス、ヒントによる減点 |
| 忘却曲線 | 1/3/7/14/30日、まちがえたときの戻し方 |
| 出題 | 重みづけ、復習の期日、認識候補の作り方 |
| 地図データ | 47県ぶんの形・大きさ・ラベル位置がある、枠に収まる、指で押せる大きさがある、**南北東西の位置関係が実際の日本と合っている**、沖縄が別枠に収まる |
| 教材データ | 47件そろっている、読みがひらがなだけ、名前が重複しない |
| 敵 | 28体、地方ごとにボスがいる、南ほど強い、**攻撃力の伸びが守備力の伸びを上回る** |
| 習熟度 | 1回のまぐれ当たりを満点にしない |

## 手動チェックリスト（実機で確認してください）

自動テストは画面の見た目とタッチ操作を見ていません。
**教室で使う前に、実際の iPad で一度は通してください。**

### iPad Safari ― 手書き

- [ ] Apple Pencil で書ける
- [ ] 指でも書ける
- [ ] **手のひらを画面につけて書いても線が乱れない**（ペンを使ったあと指入力が無視されること）
- [ ] 書いている途中で画面がスクロールしない
- [ ] 速く書いても線が角張らない
- [ ] 「一画 もどす」で直前の線だけ消える
- [ ] 「ぜんぶ けす」で全部消える
- [ ] 筆圧で線の太さが変わる（Apple Pencil）

### 画面の向き・サイズ

- [ ] 横向きで、地図が上・手書き欄が下に並ぶ
- [ ] 縦向きに回しても崩れない
- [ ] 回転したあとも手書き欄が正しい大きさになる
- [ ] iPhone のような小さい画面でもボタンが押せる
- [ ] **URLバーが出入りしても画面が飛び跳ねない**

### 学習の流れ

- [ ] 都道府県モード・県庁所在地モード・そうごうモードがそれぞれ動く
- [ ] 「かんじ／ひらがな」を切り替えるとマスがリセットされる
- [ ] ヒント3段階が順に出て、3回目でボタンが押せなくなる
- [ ] 制限時間30秒が減っていき、0で自己確認に移る
- [ ] 地方しぼりをすると、その地方の県だけ出る
- [ ] 復習モードで、まちがえた県と復習日が来た県が出る

### 採点

- [ ] 正しく書くと○になる（自動採点されたとき）
- [ ] 読めなかったときに自己確認の画面が出る
- [ ] 自己確認で自分の字と正解が並んで見える
- [ ] ○△×を選ぶと、それに応じた経験値になる

### RPG

- [ ] 敵が表示され、正解するとHPが減る
- [ ] まちがえると反撃を受けてこちらのHPが減る
- [ ] 敵を倒すと次の敵が出る
- [ ] ボスを倒すと「○○地方 せいは！」と出て、地図に色がつく
- [ ] レベルアップの演出が出る
- [ ] HPが0になっても記録が消えず、全回復して続けられる

### 音

- [ ] **最初のタップのあとに音が鳴る**（iOS の制限。1回も触らないと鳴りません）
- [ ] 設定で「鳴らさない」にすると鳴らない
- [ ] 正解・不正解・レベルアップ・撃破で音がちがう

### 図鑑・きろく

- [ ] 正解した県だけ名前と形が見える
- [ ] 両方正解した県は名産などが開く
- [ ] きろくの地図が習熟度で色分けされる
- [ ] にがてな県の一覧が出る
- [ ] 学習カレンダーに今日の印がつく

### 教師モード

- [ ] かけ算の関門が出て、正しい答えで開く
- [ ] 県べつCSVがダウンロードできる
- [ ] **CSVを Excel で開いて日本語が文字化けしない**
- [ ] まとめCSVもダウンロードできる

### 設定

- [ ] 文字サイズを変えると全画面の文字が変わる
- [ ] 色のみえかたを変えると○△×の色が変わる（形と文字は変わらない）
- [ ] ふりがなを消せる
- [ ] 左ききにするとボタンの位置が変わる
- [ ] 「きろくをぜんぶけす」は「けす」と入力しないと実行されない

### 保存とオフライン

- [ ] 何問か解いてアプリを閉じ、開き直すと続きから始まる
- [ ] ホーム画面に追加したアイコンから全画面で起動する
- [ ] **機内モードにしても全機能が動く**
- [ ] ブラウザのデータを消したあとでも、エラーにならず新規で始まる

### アクセシビリティ

- [ ] キーボードだけで、タイトルから問題まで進める
- [ ] Tab でフォーカスが見える（金色の枠）
- [ ] VoiceOver で判定と正解が読み上げられる
- [ ] OS の「視差効果を減らす」を有効にするとアニメーションが止まる
- [ ] 文字サイズ「大きい」でもボタンの文字がはみ出さない

### 長時間の使用

- [ ] 50問ほど続けて解いても動作が重くならない
- [ ] 途中で画面を回転させたり、他のアプリに切り替えたりしても壊れない

## 不具合を見つけたら

再現手順をメモしてください。とくに次の3つがあると原因を絞りやすくなります。

1. どの画面で、何をしたときか
2. 端末（iPad の機種・iOS のバージョン）と入力方法（ペン／指）
3. ブラウザのコンソールに出ているエラー

コンソールは、iPad を Mac に繋いで Safari の「開発」メニューから見られます。
Mac がない場合は、同じ手順を PC のブラウザで試すと再現することがあります。
