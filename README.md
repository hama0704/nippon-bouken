# にっぽん冒険記 ― 都道府県RPG

小学4年生が **47都道府県・県庁所在地・地図上の位置** を、
自分から何度も練習したくなるブラウザ教材です。

日本を北から南へ旅し、各地方のボスを倒しながら最後は魔王に挑みます。
学習が進むほど主人公が強くなるので、「もう1問だけ」が続きます。

- **手書き入力** ― iPad の Apple Pencil でも指でも、マス目に直接書きます
- **自動採点** ― 内蔵の文字認識が○△×を判定。読み取れないときは自分で丸つけ
- **忘却曲線** ― 翌日・3日後・1週間後…と、忘れるころに自動で出題
- **オフライン動作** ― ホーム画面に追加すればアプリのように起動し、通信不要
- **ライブラリ 0個** ― HTML / CSS / JavaScript だけ。ビルド作業も不要

---

## つかいはじめる

### いちばん簡単な方法

GitHub Pages などに置いて、URLを開くだけです（→ [docs/DEPLOY.md](docs/DEPLOY.md)）。
iPad の Safari で開き、共有ボタン →「ホーム画面に追加」でアプリになります。

### 手元のパソコンで試す

```bash
npx serve prefecture-rpg
```

表示された `http://localhost:3000` などを開きます。

> **`index.html` をダブルクリックしても動きません。**
> このアプリは ES Modules という仕組みを使っており、
> ブラウザの安全上の制限で `file://` からは読み込めないためです。
> かならず上のように簡易サーバー経由か、公開したURLから開いてください。

### テストを走らせる

```bash
cd prefecture-rpg
npm test
```

ブラウザで確認したい場合は `tests/run.html` を開きます。
採点のきまり・経験値・忘却曲線・地図データ・セーブの76件を検証します。

## 学習モード

1. **都道府県モード** ― 光っている県の名前を書く
2. **県庁所在地モード** ― 光っている県の県庁所在地を書く
3. **そうごうモード** ― 同じ県について、名前と県庁所在地の両方を書く

難易度は「かんじだけ／ひらがなOK」「制限時間なし／30秒／15秒」
「全国／地方別」「ふつう／にがてな県だけ」を組み合わせて選べます。

## 採点のきまり

| 書いたもの | 判定 |
|---|---|
| 埼玉 | ○ |
| 埼玉県 | ○（「県」は付けても付けなくてもよい） |
| さいたま | △（読みは合っているがひらがな） |
| さいたまけん | △ |
| 崎玉 | ×（「おしい！かんじが1つちがうよ」と伝える） |
| 千葉 | ×（「それは千葉県だよ」と伝える） |

変えたいときは [docs/CUSTOMIZE.md](docs/CUSTOMIZE.md) を参照してください。

## 経験値

| できごと | 経験値 |
|---|---|
| はじめて漢字で正解 | 100 |
| はじめてひらがなで正解 | 60 |
| 2回目の正解 | 50 |
| 3回目以降の正解 | 20 |
| **前回まちがえた問題に正解** | **120** |
| にがて克服ボーナス | まちがえた回数 × 20（最大120） |

ヒントを使うと ×0.9／×0.75／×0.5 に減ります。

いちばん多いのが「まちがい直し」であることが、この教材の考え方そのものです。
**同じ県を繰り返すより、わからなかった県に向き合うほうが強くなります。**
実際に通しで自動プレイさせると、正答率35%の想定でクリアしたときのレベルは19、
正答率80%の想定では14でした。つまずいて粘った子ほど強くなります。

---

## 大事にした考え方

**まちがえても失うものはありません。** HPが0になっても経験値も記録も減らず、
全回復して同じ敵に挑み直します。ここで罰を与えると
「わからない問題を避ける」ようになり、学習として最悪の状態を招くためです。
戦闘はがんばりの見える化であって、罰の道具ではありません。

**機械が読めなかったことを、子どものせいにしません。** 文字認識に自信がないときは
「読み取れませんでした」ではなく「こたえと見くらべてみよう」と表示し、
自分の字と正解を並べて見せます。見比べる作業そのものが有効な学習（自己評価）なので、
これは仕方のない代替手段ではなく、正式な学習手段として位置づけています。

## プライバシー

学習記録は端末のブラウザ内（localStorage）にだけ保存されます。
外部に送信することはなく、サーバーもアカウントも必要ありません。
端末を替えると記録は引き継がれないため、
必要に応じて「せってい → きろくを書き出す」でバックアップしてください。
